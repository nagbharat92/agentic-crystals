# Alexander's Agentic Crystals

**You manifest. It executes.**

A single-page parody of AI agent hype: crystals that interpret your intentions and act on them with absolute confidence.

## Live site

[Visit Alexander's Agentic Crystals](https://nagbharat92.github.io/agentic-crystals/)

## Features

- Peaceful mountain-retreat styling with softly glowing crystals.
- Seven agentic products, testimonials, and interactive execution demos.
- Rotating purchase toasts. No real checkout, backend, or account connections.
- Responsive layout and reduced-motion support.

## Local preview

Open `index.html` in your browser. No installation or build step is required.

## Hosting

GitHub Pages serves the site from the `main` branch, using the repository root.
